# Momentum Scanner

Screen stocks for momentum signals using technical indicators and insider activity.

## Features

- Batch quotes sorted by daily performance
- Technical analysis (RSI, MACD, Bollinger Bands)
- Insider trading activity for confirmation
- Async concurrent requests

## Usage

```bash
pip install vectrade
export VECTRADE_API_KEY=vq_your_key_here
python main.py
```
